###Rock Paper Scissors###

This is my first C++ project. a simple rock-paper-scissors in the terminal. 

I thought I should do a full scale production grade notes app to take notes on-the-fly as my first project but got humbled at the part of even making a window. so after this I will tackle the notes app or do a project bigger than this one atleast.

What I found slighlty difficult was properly nesting both the while loops. 
And no, zero AI use, didnt use a template either.

To run this project, you can copy the script in main.cpp, paste it in your code editor, and run the script. Make sure that you have the C++ extensions and a compiler installed.
